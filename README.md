# MY-HOME-GROUP

## Vehicle Duration Management System

My Home Group is a vehicle duration management system for tracking:

- Vehicle Management
- Entry / Exit Tracking
- Automatic Duration
- Calendar
- Reports
- Notifications
- User Authentication
- Admin User Management
